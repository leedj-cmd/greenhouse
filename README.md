# Greenhouse (Dr. Plant) 🌿

식물 질병 진단 앱 '닥터 플랜트' 프로젝트입니다.

## 주요 기능
- 이미지 선택 및 촬영 (이미지 피커)
- AI 정밀 진단 (Gemini 1.5 Flash 연동)
- 식물 이름, 병명, 증상 분석 및 피드백 제공

## Getting Started
이 프로젝트는 Flutter로 개발되었습니다.

1. `.env` 파일을 생성하고 `GEMINI_API_KEY`를 설정하세요.
2. `flutter pub get`으로 패키지를 설치하세요.
3. `flutter run`으로 앱을 실행하세요.
